List Vault

A collaborative shopping list app built with Flutter and Supabase

Try Live Demo Download for Android

Recruiter or reviewer? Open the demo, tap Weekly Shopping List → Continue as Guest, then join the same family from your phone with the code shown.

Features

👨‍👩‍👧‍👦

Family Collaboration

Share shopping lists with your family in real-time. Everyone stays synchronized automatically.

🔄

Real-time Sync

Changes appear instantly across all devices using Supabase real-time subscriptions.

🎙️

Voice Input

Add items hands-free using voice recognition. Perfect while cooking or driving.

📊

Categories

Organize items by category: Fruits, Vegetables, Dairy, Bakery, and more.

📅

Weekly Lists

Automatic weekly rollover with carry-over for uncompleted items.

🌙

Dark Mode

Easy on the eyes with built-in dark mode support for nighttime shopping.

🎉

Event Lists

Create special lists for parties, holidays, and events.

✅

Quick Add

One-tap to add frequently purchased items from your history.

Technology Stack

Flutter Dart Supabase PostgreSQL Real-time Subscriptions Speech to Text Provider State Management Hive Local Storage Material Design

Key Achievements

  • Real-time Collaboration: Implemented PostgreSQL change streams for instant multi-device synchronization
  • Cross-device Family Groups: Families stored in Supabase and joined from any device with a short 6-character code
  • Cross-platform: Single Flutter codebase running on Android and the web (desktop and mobile browsers)
  • Smart Features: Voice input, automatic weekly rollover, and quick-add from history
  • Modern UI/UX: Responsive design with dark mode and smooth animations
